CSM WYVERN — ALL IN 1 PWA (OFFLINE PDF EDITION)

This package is designed for vessel/offline use. The PDF import function uses the bundled pdf-engine.js and does NOT load PDF.js or any CDN from the internet.

INSTALL / RUN
1. Extract this ZIP to the vessel computer.
2. For PWA installation, serve the folder through HTTPS or localhost. Example with Node.js: npx http-server -c-1 .
3. Open the app through the local server and choose Install App in the browser when offered.
4. After the first load, the service worker caches the application core for offline use.

PDF IMPORT
- PDF -> Table works locally for common text-based PDFs, including many PDFs using FlateDecode compression.
- Scanned/image-only, encrypted, or unsupported PDFs may require OCR/external conversion.
- Review imported tables before treating them as official records.

DATA / REPORTS
- Use Export JSON / Import JSON for backup and transfer.
- Use the Office Reporting Center and Print / PDF for office-ready reports.
- Keep signed/original controlled documents in the vessel/company approved document system.
